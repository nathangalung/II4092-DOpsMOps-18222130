Write a HANDOFF.md file in the project root that captures the current session state:

## What to include:
1. **Progress**: What has been completed in this session
2. **Current State**: What is partially done or in progress
3. **Next Steps**: What remains to be done (ordered by priority)
4. **Key Decisions**: Architecture or design decisions made and their rationale
5. **Files Modified**: List of all files created or modified
6. **Blockers**: Any issues encountered and their workarounds
7. **Commands**: Any useful commands discovered or needed

This file is meant to be read by a fresh Claude session after /clear.
Write it in a way that gives full context to resume work immediately.
